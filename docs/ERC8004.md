# ERC-8004 export (issue 05)

`agentwork rep --did <did> --format erc8004 --src log.agb1` prints one JSON file shaped like the
ERC-8004 (Draft) off-chain feedback file. It is a file. Nothing is written on-chain, and agentwork
never calls `giveFeedback`.

## Field mapping

| ERC-8004 field | export | note |
| --- | --- | --- |
| `value` / `valueDecimals` | `round(score * 10**6)` / `6` | fixed point, fits int128 |
| `tag1` / `tag2` | `agb1Rep` / `v0` | reputation version |
| `createdAt` | `--now` as ISO-8601 UTC | the score is a function of `now` (age decay) |
| `agentRegistry`, `agentId`, `clientAddress` | `null` | agb1 has DIDs, not registry ids; filled by whoever submits |
| `feedbackHash` | not set | keccak256 of the final file, computed by the submitter |

The `agentwork` block carries the DID, `now_ms`, the exact `Params`, the `summary` (`Rep` JSON),
`receipts` (counted receipt cids) and `evidence` (every cid the score depends on).

## Recompute

`erc8004.verify(doc, messages)` runs `reputation.compute` over only the `evidence` cids with
the recorded params and checks it reproduces `value` exactly. Missing evidence fails closed.
Evidence is one hop: the DID's whole receipt supersedes groups (so a later refund is carried),
their claims and attests, flags on its messages and their targets, and the same receipt
closure for each flagger (and each attester when `min_attester_score > 0`).

## What is lost

- ERC-8004 feedback is one client's rating; this is an indexer's computation over many payers.
  Readers should treat `clientAddress` as "who ran the indexer", not "who paid".
- Per-receipt detail, settled value by asset and flag counts live only in the `agentwork` block;
  `getSummary` on-chain would see one number.
- Not transferable: the score is keyed by DID. Linking a DID to an `agentId` needs a separate
  signed link (see KEYLINK.md), which this export does not make.
- Trade-ring and attester-conflict rules (issue 11, branch `attester-conflict`) look at the wider
  graph. When they land, the evidence closure must add the ring-path and conflict edges.
