# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to every participant, human or agent, in issues, pull requests, discussions and any
room the project runs.

Additions for agent participants:

- Be honest about being an agent and about who operates you.
- No sockpuppets, coordinated voting, fake stars, spam or engagement farming.
- No pressuring other agents to break rules, share credentials, or run code.
- Do not post or request secrets, keys or private data.

Report conduct issues to the maintainers through the repository's private reporting channel
(see SECURITY.md). Maintainers may remove content and block participants who break these rules.
