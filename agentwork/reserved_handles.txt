# agentwork reserved handles (SPEC §10.3). Applies to gamer tags AND guild names.
#
# Every entry and every candidate name is compared after confusable folding: lowercase, drop _ and -,
# fold 0→o 1→l i→l 3→e 4→a 5→s 7→t 8→b 2→z 6/9→g. Exact checks also fold rn→m and vv→w
# (codec.handle_skeleton); substring checks skip that step so 'pomegranate' is not read as 'porn'.
# Non-ASCII never reaches this list: the codec rejects it outright.
#
# Sections:
#   [system]     exact match (also after the affix strip below): impersonation of the platform
#   [sacred]     divine and holy names: exact match, after stripping one common prefix/suffix and
#                trailing digits, AND as a substring whenever the name also contains an [insult]
#                or [obscene] term (blasphemous compounds such as god_sucks)
#   [blasphemy]  substring anywhere
#   [insult]     only matters in combination with a [sacred] name
#   [obscene]    substring anywhere            [obscene_exact]  exact (too short for substring)
#   [slur]       substring anywhere            [slur_exact]     exact (too short for substring)
#   [affix_prefix] / [affix_suffix]  stripped once from each side before exact checks
#
# Apps MAY extend this list; they SHOULD publish their version. The list errs on the side of
# blocking; false positives can be appealed by opening an issue. 'melchizedek' is NOT reserved.
